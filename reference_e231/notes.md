# E231系 近郊タイプ（1000番台）観察メモ

reference_e231 の写真を見て読み取った特徴です。描くときは、必ずこのメモと見比べること。
（ ）内は根拠にした写真の番号です。寸法は写真から読んだ目安で、一般に知られている車両寸法でおおよそ確かめています。

## 車体全体
- 車体は無塗装のステンレス。銀色だが白っぽく光るのではなく、少し黄みや灰色を帯びた鈍い銀色に見える。細かい縦の継ぎ目と、空や地面の色をぼんやり映す（01, 02, 09）
- 1両は長さ約20m。側面の高さ（屋根の縁から車体の下端まで）は約2.9m、屋根の上端はレール面から約3.6m（01, 17）
- 幅の広い車体で、側面の下のほうが内側へすぼまっている。真横から見ると、側面の下端が丸く折れ込んで見える（06, 07, 10）
- 屋根は灰色で、側面より暗い。縁はゆるく丸い。屋根の縁のすぐ下に細い緑の線が見える（01, 09, 14）
- 床下には灰色の機器箱と、灰色の台車（車輪2軸）。台車は車体の両端寄りに1つずつ（01, 20）

## 寸法（資料と写真から）
- 車体幅 2,950mm（従来の通勤車 2,800mm より広い拡幅車体）— 出典：Wikipedia「E231 series」（検索結果で確認）
- 台車：電動車 DT61、付随車 TR246 — 同上
- 軌間 1,067mm。車輪は中心線から左右約0.53mにしかなく、車体は片側約0.95mも張り出す。台車は車体の下の深い影の奥にある
- 写真01からの実測（ドア幅1.3mを基準）：車輪径 約0.8〜0.86m、軸距 約2.0〜2.1m、台車中心は車端から約3m（台車中心間 約13.8m）
- ※台車中心間・軸距・車輪径は公式資料では未確認（このセッションからWikipedia本体に接続できなかったため）

## 帯（湘南色）
- 窓のすぐ下に、**上が細いオレンジ、下が太い緑**の2色の帯が側面をまっすぐ走る（01, 02, 09）
  - 太さの比はおよそ オレンジ1：緑2〜2.2
  - 2本合わせて、側面の高さの約15％。帯の上端は窓の下辺とほぼ同じ高さで、屋根の縁から測って側面の約65〜68％の位置
  - 色の見え方：オレンジは赤みの少ないみかん色（黄色寄り）。緑はやや青みのある明るい緑で、日陰では深い緑になる。蛍光色のような鮮やかさはない
- 屋根の縁の下に、細い**緑一色の帯**（側面の高さの約5〜7％）（01, 09, 14）
- **ドアの部分では帯が途切れる**。ドアは銀色のまま（01, 02, 14）
- 前面では、黒い窓まわりのすぐ下に、同じオレンジと緑の帯が横一直線に入る（04, 05, 15）

## 先頭車の側面（写真01を画素単位で実測、4つのドア幅がそろうように遠近を補正。位置は連結側の端から）
- 小窓 0.21〜0.95 / ドア中心 2.45 / 大窓 3.91〜5.90 / ドア 7.43 / 大窓 8.92〜10.98 / ドア 12.47 / 小窓 13.97〜14.68 / ドア 16.17 / 乗務員扉 17.88〜18.60 / 運転台の窓 18.82〜19.52（m）。運転台横の窓は小さく高い位置（高さ約2.37〜2.86m）
- ドアは枠を含めて幅約1.4m
- 高さ（レール面から）：窓 1.95〜2.82m（大窓は約2.0×0.87m）、ドアの窓 2.0〜2.78m、屋根下の緑帯 3.03〜3.14m、オレンジ 1.69〜1.77m、緑 1.45〜1.67m

## ドアと窓（普通車）
- 片側に**4つの両開きドア**。どの車両でもほぼ同じ間隔で並ぶ（01, 02）
  - ドアの幅は約1.3m。両開きの扉それぞれに、縦長で角の丸い小窓が1つずつ（合わせて2つ）
  - ドアの中心どうしの間隔は約4.8m。車端からいちばん端のドアまでは約2.5m
- 窓の並び（中間車）：`[小窓] ドア [大窓] ドア [大窓] ドア [大窓] ドア [小窓]`（02）
  - 大窓は横長で、黒く暗く見える（車内は描かない）。窓の上下の高さは、側面の上から約25〜62％のあたり
  - 車端の小窓はほぼ正方形
- 先頭車：運転台の後ろに**乗務員扉**（細い扉に縦長の窓）。帯の緑がここで縦長に見える（01, 14）。その後ろに小窓が1つあって、いちばん前のドアへ続く

## 前面（運転台の顔）— 写真04をほぼ正面から実測（車体幅2.95mを基準に約87px/m、高さはレール面から）
- 黒い面（窓＋行先表示）：幅 ±1.29m（顔の幅いっぱい近く）、高さ 1.89〜3.53m。上の角は丸い
- 前照灯：黒い面の上の隅、±0.9m・3.35m / 行先表示：±0.38m・3.27〜3.47m
- 帯：オレンジ 1.67〜1.80m、緑 1.46〜1.67m（側面の帯と角でつながる）
- 下の黒い帯：1.14〜1.43m、両端に尾灯 / 車体の下端：約1.0m
- スカート：車体のすぐ下（約0.95〜0.42m）に密着して付く。上は広く（±1.32m）、下の両角を大きく斜めに落とす。中央に連結器
- 側面は平らではない：下から約2/7（1.0〜1.65m）は内側へまっすぐ傾いた面。そこから上はほぼ垂直で、肩でわずかに入る（拡幅車体）。顔の輪郭もこの断面に沿う

- ほぼ平らな顔で、四隅は大きく丸い。上から見ると、側面から前面へ丸く回り込む（06, 07, 15）
- 上半分は**大きな黒いガラス面**。前面の幅のほぼ全部、高さの約45％を占める（03, 04）
  - 中央の上の端に行先表示（オレンジ色に光る文字。絵では文字を描かず、細長い暖色の小さな面だけ）
  - **前照灯は黒いガラス面の上の左右の隅**に1つずつ。小さな丸い灯り（03, 04）
- 黒い面のすぐ下にオレンジと緑の帯、その下に細い黒い帯があり、その両端に**赤い尾灯**（05）
- いちばん下には、白っぽい銀色の大きな**スカート**（排障器）。台形で、下の角が丸い。中央に連結器と、細かい機器の黒い影（04, 05, 15）
- 屋根の上の前端には、小さな黒い突起（無線アンテナなど）（03）

## 2階建てグリーン車（4号車＝サロE230、5号車＝サロE231）
- 車体の両端（台車の上）は**平屋**で、普通の高さに窓が並ぶ（3枚ほど）。その内側に、片開きのドアが1つ（09, 11）
- 中央の約2/3が**2階建て**
  - **下の段の窓**は低く、側面の下端近く（レール面から1m前後）に4〜5枚
  - **上の段の窓**は高く、屋根の縁のすぐ下に5〜6枚。屋根の丸みに沿って少し内側に傾き、上の角が丸い
  - オレンジと緑の帯は、上の段と下の段の窓の**あいだ**を走る。平屋部分の帯より少し高い位置になり、つなぎ目で帯が**段差**になる（09）
  - 2階建て部分は車体の**下端が台車の間で一段下がり**、レールのすぐ上まで落ち込む（09, 10）
  - 屋根は普通車より高い（レール面から約4m）。横から見ると、編成の中でこの2両だけ屋根がふくらんで見える（11, 15, 16）
- 平屋部分の窓の上にも、緑の細帯が入る（09）
- 4号車と5号車は向きが逆。2両の間の連結面をはさんで左右対称に見える（11）

## 屋根の上の機器
- 冷房装置は1両に1台。銀色で、肩の丸い大きな箱。上面に丸いファン、側面にグリル（14）
  - **普通車（中間車）**：屋根のほぼ中央（02, 19）
  - **先頭車**：中央ではなく、運転台と反対側（連結側）へ寄っている。連結側の端から約1/3の位置。運転台側の屋根には何もない（14）
  - **2階建てグリーン車**：2階建て部分の屋根には**載っていない**。平屋部分（2両組の外側の端）の屋根の上に1台（10, 11）
- 電動車（モハE231）には**シングルアーム式パンタグラフ**が1基（13）
  - くの字に折れた1本の腕と、その上に横長の舟（集電舟）。台座には白い碍子
  - 舟は横から見ると細い横棒で、両端が下へ曲がった角のように見える
- 位置の目安：10両側に2基、5両側に1基（16・17で、屋根の上に突き出すパンタグラフの数から推定）
- 架線は、架線柱の腕から吊られた2本の線（上が吊架線、下がトロリ線）で、間を細い吊り線がつなぐ（13, 17）

## 10両＋5両の連結部
- 15両編成は、10両編成と5両編成を連結している。東海道線では1〜10号車が10両側、11〜15号車が5両側（グリーン車は4・5号車なので、10両側に入る）
- 連結部では、**運転台の顔どうしが向き合う**（05, 15）
  - 通り抜けの扉がないので、平らな前面どうしがすき間をあけて並ぶ。そこだけ屋根の線が一度下がって、編成の輪郭が「くびれ」て見える
  - 黒い前面ガラスの一部、前面の帯、白っぽいスカートの角が、横から少しだけ見える
  - 連結器のまわりは暗い影になる

## 編成全体と橋（構図の参考）
- 15両は約300m。カーブで斜めに見ると、手前の車両は大きく、奥の車両は細い縦線の集まりのように詰まって見える（08, 16, 19）
- 橋の上では、**橋脚・架線柱・パンタグラフが一定のリズムで並ぶ**（17）
  - 架線柱は細い鉄柱（または格子の柱）で、上に腕を張り出す
  - 柱の間隔は約50m（車両2両半ほど）
- 橋桁は箱形で、側面に水平の影の線が入る（17）
- 水面の映り込みは横に揺れて切れ切れになり、橋脚の影が縦に長く伸びる（17）
